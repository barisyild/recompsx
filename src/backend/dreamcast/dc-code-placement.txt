# The runtime's and the backend's hot code in the SH-4's instruction cache, for a game with no
# placement of its own (ADR-0043, amended 2026-10-04): scripts/build-dc.sh uses it when
# games/<SERIAL>/dc-placement.txt is missing. The sections are the same in every game — the GTE and
# polygon cores, the scene build, the DMA list walk, the GPU's and the memory map's slow paths — so
# where they go need not wait for a game's own round. A game's own file places them again, with
# its own code, and supersedes this one.
#

#

# E-148, E-151 and E-152 for r138's, r139's and r140's): the 108 runtime and backend sections of
# Crash 3's round r140 placement (games/SCUS94244/dc-placement.txt; generated code left out).
# E-134's measure of the idea, on r126's: on another game, Crash Bash's Ballistix (18800..20300),
# 19.24 ms a frame with no placement, 17.77 with this, 16.76 with its own — 59 % of its own
# placement's gain; on Crash 3 itself 53-57 %. A round over several games' traces with only these

#
